# 디지캐럿뇨 번역 용어집

번역기가 읽는 확정 표기는 `glossary.tsv`에 있다. 이 문서는 그 근거와 규칙이다.

## 기준

- 인물 표기는 사용자가 지정한 나무위키 `디지캐럿` 문서를 기준으로 하고,
  게임 원문에서 실제 표기와 빈도를 대조했다.
- 게임 원문 모집단: `messages.json` 4,317개 + `ui_strings.json` 393개 = 4,710단위
- 크로스오버 인물(`ミルフィーユ`, `ラッキースター`)은 **같은 저장소의 갤럭시
  엔젤 프로젝트 확정 표기와 일치시켰다**(`밀피유`, `럭키 스타`).

## 사용자가 확정한 판단

세 가지는 규칙끼리 충돌해 사용자에게 물어 확정했다.

1. **`・` 처리 — 나무위키 표기 우선.**
   스킬의 원본 보존 규칙은 "원문에 `・`가 있으면 번역도 같은 자리에 유지"지만,
   이 작품은 나무위키 표기를 기준으로 삼기로 했으므로 그쪽을 따른다.
   - `ラ・ビ・アン・ローズ` → **라비안 로즈** (`라・비・앙・로즈` 아님)
   - `デ・ジ・キャラット` → **디지캐럿**
   - `プチ・キャラット` → **푸치캐럿**

   **주의**: 이건 이 세 이름에 한한 의도적 예외다. 다른 곳의 `・`는 그대로
   유지한다(예: `でじこ・イン・ワンダーランド`의 가운뎃점). 나중에 원본 대조
   검사가 이 세 건을 위반으로 잡으면 예외로 처리할 것.

2. **`店長さん` → `점장 씨`.**
   스킬 규칙(`さん`→`씨`)을 그대로 적용한다. 한국어로는 `점장님`이 더
   자연스럽지만, 원문에 없는 높임을 만들지 않는 쪽을 택했다. 112회 등장.

3. **캐릭터 말끝 어미는 음역해서 유지한다.**
   한국어 말버릇으로 의역하지 않는다. 캐릭터 구분이 이 어미로만 되는 대사가
   많다.

   | 원문 | 번역 | 화자 |
   |---|---|---|
   | `にょ` | 뇨 | でじこ(데지코) |
   | `ゲマ` | 게마 | ゲマ(게마) |
   | `ぴょ` | 뾰 | ぴよこ(삐요코) |
   | `にゅ` | 뉴 | ぷちこ(푸치코) |
   | `ゲバ` | 게바 | 게마게마단 단원 |

   `ゲマ`는 인물 이름이면서 동시에 어미다. 문장 끝에 붙은 것은 어미,
   그 외는 인물이다 — 자동 치환하지 말고 문맥을 봐야 한다.

## 게임 내 설정에서 확인한 것

원문이 직접 밝히고 있어 번역 시 참고할 것.

- `うさだ`의 본명은 `うさだヒカル`(우사다 히카루)이고, **본인은 `うさだ`라고
  불리면 화낸다**. 원문이 두 표기를 구분해 쓰므로 통일하면 안 된다.
- `うさだあかり`(우사다 아카리)는 히카루의 **사촌언니**로 톱아이돌 겸 대여배우다.
  `うさだ`와 별개 인물이니 `うさだ` 치환 규칙이 이쪽을 건드리지 않게 할 것.
- `ぴよこ`는 `ブラックゲマゲマ団`의 수령이고 `口からバズーカ`가 특기다.
- `カイ`는 게마게마단 중장(치과의), `クウ`는 소좌(내과의)로 삐요코의 소꿉친구.

## 부분 문자열 충돌 (치환 시 주의)

짧은 쪽부터 치환하면 긴 쪽이 망가진다. **반드시 긴 쪽을 먼저 확정**할 것.

- `ゲーマーズ` ⊂ `ブラックゲーマーズ`
- `ブラックゲマゲマ` ⊃ `ブラゲマ`(약칭이지만 별개 문자열)
- `うさだ` ⊂ `うさだヒカル`, `うさだあかり`, `うさだ屋`
- `でじこ` ⊂ `でじこ屋`, `でじこ・イン・ワンダーランド`
- `ゲマ` ⊂ `ゲマコイン`, `ゲマゲマ団`, `ブラックゲマゲマ`

## 검증

번역이 진행되면 스킬 도구로 확인한다.

```bash
python "C:/Users/Timon/.claude/skills/korean-game-patch/scripts/build_glossary.py" \
  verify --glossary assets/translation/glossary.tsv --pairs <번역캐시.json>
python "C:/Users/Timon/.claude/skills/korean-game-patch/scripts/build_glossary.py" \
  variants --glossary assets/translation/glossary.tsv --pairs <번역캐시.json>
```

`verify`는 확정 표기를 안 쓴 곳이 몇 군데인지, `variants`는 그 자리에 실제로
뭐가 쓰였는지를 낸다. **둘 다 돌려야 한다** — verify만 보고 변형을 머리로
짐작하면 반드시 빠뜨린다.

## 미확정 (번역 착수 후 표본 보고 판단)

- 아이템·카드 이름 다수(`ターボカード`, `店長カード`, `おジャマ` 등)는
  일반명사 조합이라 용어집에 넣지 않았다. 번역 표본이 나오면 반복 표기가
  흔들리는지 확인해 필요한 것만 추가한다.
- `ゲーマーズ`는 실존 상점명(Gamers)이라 `게이머즈`로 두었다. 국내 정발
  표기가 따로 있으면 교체할 것.
