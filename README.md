# DigiCommunication Nyo 한국어 번역 프로젝트

GBA판 `DigiCommunication Nyo - Datou! Black Gemagema Dan (Japan)`의 한국어 팬 번역 작업을 이어가기 위한 **소스/번역 데이터 저장소**입니다.

이 저장소의 목적은 완성 ROM이나 게임 자산을 배포하는 것이 아니라, 다른 개발자가 번역문을 수정하고 추출/재삽입 도구를 개선하며 작업을 이어갈 수 있도록 **도구 코드, 추출된 텍스트/메타데이터, 번역 작업 데이터**를 보존하는 것입니다.

> 이 저장소에는 ROM, BIOS, 세이브, 세이브스테이트, 원본 이미지, 번역 이미지, 폰트 파일, 빌드된 패치 파일을 포함하지 않습니다.

## 현재 텍스트 상태

최종 작업 기준:

- 재삽입 대상 메시지: **4,669 / 4,669 번역**
- recovered 메시지: **142개**
- 고정폭 raw UI 번역 적용: **311개**
- 12x12 / 10x10 한글 폰트용 완성형 음절: **2,350자**
- 이름 입력/HUD용 8x8 확장 및 받침 처리 도구 포함

그래픽/자막/카드/메뉴 이미지도 로컬 최종 빌드에서는 작업되었지만, **이미지 자산은 공개 Git 범위에서 의도적으로 제외**합니다. 따라서 이 저장소만으로 기존 최종 그래픽 상태를 byte-for-byte 재현할 수는 없습니다.

자세한 과거 조사/수정 기록은 `STATUS.md`를 참고하세요.

## 원본 확인

작업 기준 일본판 ROM의 SHA-256:

```text
3A098B5963DAF8BF38D67780F95325158FE09783980B1B74FA24BA02ECD16A5C
```

- 크기: `16,777,216 bytes`
- 게임 코드: `BDKJ`

다른 리비전이나 이미 수정된 ROM에서는 오프셋과 압축 구조가 달라질 수 있습니다.

원본 ROM은 저장소에 포함하지 않습니다. 본인이 정당하게 소유한 원본에서 직접 준비해 주세요.

## 저장소 구성

### `assets/translation/`

공개하는 번역 작업 데이터입니다.

- `messages.json` — 메인 메시지 작업 파일. `mcm_offset`/`header`로 위치를 식별하며 `translation`이 한국어 번역문입니다.
- `recovered_messages_ko.json` — 일반 추출에서 빠졌던 복구 메시지 번역
- `ui_strings.json` — ROM에서 추출한 고정폭/raw UI 원문 및 위치 메타데이터
- `ui_strings_ko.json` — 고정폭/raw UI 문자열 번역
- `GLOSSARY.md`, `glossary.tsv` — 용어/표기 통일 자료
- `hangul_map.json` — 현재 한글 코드 매핑 자료

`messages.json`, `ui_strings.json`, `ui_strings_ko.json`, `recovered_messages_ko.json`에는 번역과 위치 매칭을 위해 일본어 원문이 함께 들어 있습니다. **이처럼 텍스트 형태로 추출된 원문/오프셋/매니페스트는 개발 자료로 Git에 포함할 수 있습니다.** 다만 일본어 원문 자체의 권리는 원 게임 권리자에게 있으며 프로젝트의 MIT 라이선스 대상은 아닙니다. 자세한 내용은 `LICENSES.md`를 참고하세요.

### 기타 `assets/` 메타데이터

이미지 자체는 제외하지만, 후속 작업을 위해 `build_invariants.json`, `captions_index.json`, `images_index.json`, 이미지/OBJ의 JSON·TSV 매니페스트와 작업 노트는 공개할 수 있습니다. 이 파일들은 오프셋, 크기, 파일명, 빌드 규칙 같은 개발용 메타데이터이며 실제 그래픽 바이너리를 포함하지 않습니다.

### `tools/`

프로젝트에서 작성/수정한 Python 도구입니다.

- 미니게임/상태 UI 관련 프로젝트 전용 패처
- IPS 생성/검증 도구
- MBM 유틸리티
- `tools/upstream_snapshot/` — 상위 공용 GBA toolkit에서 이 프로젝트를 위해 변경된 핵심 도구의 보존본과 해시 기록

공개 범위는 **소스 코드만**입니다. 도구가 참조하는 게임 원본 바이너리, 이미지, 폰트는 포함하지 않습니다.

## 번역을 이어서 수정하는 방법

### 1. 환경

권장 환경:

- Python 3.11 이상
- Pillow

```bash
python -m pip install -r requirements.txt
```

### 2. 원본 메시지 다시 추출

본인이 준비한 원본 ROM에서 메시지 구조를 다시 확인하려면:

```bash
python tools/upstream_snapshot/gba_text_extract.py \
  --rom "path/to/original.gba" \
  --output "messages_extracted.json"
```

이처럼 **텍스트/JSON 형태로 추출한 결과는 후속 개발에 필요하면 Git에 포함해도 됩니다.** 단, ROM 자체나 ROM에서 잘라낸 바이너리 블록·그래픽·음원 같은 실제 게임 데이터 파일은 포함하지 않습니다.

### 3. 번역 수정

일반 대사는 `assets/translation/messages.json`의 각 `translation` 필드를 수정합니다.

중요:

- `mcm_offset`, `mcm_offset_hex`, `header`는 위치 식별 정보이므로 이유 없이 변경하지 않습니다.
- `$0`, `$1`, `%d` 같은 게임용 토큰은 보존합니다.
- 줄바꿈 `\n`은 실제 화면 레이아웃에 영향을 줍니다.
- 고정 슬롯 문장은 원문보다 긴 번역이 들어가지 않을 수 있으므로 실제 인코딩 바이트 길이를 확인해야 합니다.
- 캐릭터 말투와 고유명사는 `GLOSSARY.md` / `glossary.tsv`를 우선 기준으로 삼습니다.

고정 UI는 `ui_strings_ko.json`, 복구 메시지는 `recovered_messages_ko.json`을 수정합니다.

### 4. 도구 변경 검증

최소 정적 검증:

```bash
python -m compileall -q tools
```

JSON 수정 후에는 JSON 파싱 오류가 없는지 반드시 확인하세요.

완전한 ROM 빌드는 로컬에서 별도로 보관하는 이미지/폰트/원본 추출 자료가 추가로 필요합니다. 공개 저장소는 이미지 자산을 포함하지 않으므로 **소스 저장소 단독 one-click 최종 빌드는 지원하지 않습니다**.
