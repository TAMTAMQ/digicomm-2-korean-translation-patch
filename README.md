# 디지커뮤니케이션 2 한국어 번역 패치

GBA판 **디지커뮤니케이션 2**의 비공식 한국어 팬 번역 패치 프로젝트입니다. 패치 대상 일본판 ROM의 원제/파일명은 `DigiCommunication Nyo - Datou! Black Gemagema Dan (Japan)`입니다.

최신 패치 파일과 배포 버전은 GitHub **Releases**에서 확인해 주세요. 플레이 가능한 수준까지 번역·검증했지만 이후 오역 수정, 미번역 발견, 표현 개선, 그래픽/호환성 수정이 계속 반영될 수 있습니다.

> 🙏 **이 패치는 AI 번역을 기반으로 제작되었습니다.** 게임을 플레이하는 데 지장이 없도록 여러 차례 수정·검증했지만, 사소한 오역이나 어색한 표현, 캐릭터 말투가 문맥과 맞지 않는 부분이 남아 있을 수 있습니다. 완벽한 상업 번역 수준의 품질을 기대하기보다는, 이러한 부분을 감안하고 플레이해 주세요.
>
> ⚠️ 특히 화자나 앞뒤 상황을 추출된 한 문장만으로 확정하기 어려운 대사는 AI가 문맥을 잘못 판단했을 가능성이 있습니다. **번역을 수정하거나 다른 프로젝트에서 참고할 때는 한국어 번역만 그대로 가져가지 말고 `messages.json`의 일본어 원문과 실제 게임 문맥을 반드시 함께 확인해 주세요.**
>
> 💬 오역, 미번역 일본어, 글자 깨짐, 진행상 문제 등을 발견하시면 GitHub Issues에 화면/상황과 함께 제보해 주세요.

대량 번역과 일부 길이 축약에는 `gemma-4-26b-a4b-it-qat` 기반 AI 번역을 사용했고, 이후 게임 구조에 맞춘 수정과 반복적인 빌드/화면 검증을 거쳤습니다. **AI 번역을 사용했다는 사실과 번역의 정확성은 별개의 문제이므로, 번역문을 재사용하거나 수정할 때 원문 대조를 권장합니다.**

## 1. 패치 대상 원본

작업 기준 일본판 ROM:

```text
SHA-256: 3A098B5963DAF8BF38D67780F95325158FE09783980B1B74FA24BA02ECD16A5C
크기:    16,777,216 bytes
게임코드: BDKJ
```

다른 리비전이나 이미 수정된 ROM에서는 오프셋과 압축 구조가 달라 패치가 정상 동작하지 않을 수 있습니다.

**원본 ROM은 이 저장소와 Releases에 포함하지 않습니다.** 반드시 본인이 정당하게 소유한 일본판 원본에서 준비해 주세요.

## 2. IPS 패치 적용 방법

배포용 패치 파일과 버전 정보는 GitHub **Releases**에서 관리합니다.

### 준비물

1. 위 SHA-256과 일치하는 일본판 원본 ROM
2. GitHub Releases에서 받은 `.ips` 패치 파일
3. IPS 패처

Windows에서는 `Lunar IPS (LIPS)` 같은 일반적인 IPS 패처를 사용할 수 있습니다. 다른 IPS 호환 패처를 사용해도 됩니다.

### Lunar IPS 기준 적용 순서

1. 원본 ROM을 안전한 위치에 **백업**합니다.
2. `Lunar IPS`를 실행합니다.
3. `Apply IPS Patch`를 선택합니다.
4. GitHub Releases에서 받은 `.ips` 파일을 선택합니다.
5. 패치를 적용할 일본판 원본 `.gba` 파일을 선택합니다.
6. 패치 완료 메시지가 나오면 해당 ROM을 mGBA 등 GBA 에뮬레이터에서 실행합니다.

원본을 직접 덮어쓰기 싫다면 먼저 ROM 파일을 복사한 뒤 **복사본에 패치를 적용**하는 것을 권장합니다.

### 원본 ROM 확인

이 패치는 아래 원본을 기준으로 제작되었습니다.

```text
SHA-256: 3A098B5963DAF8BF38D67780F95325158FE09783980B1B74FA24BA02ECD16A5C
크기:    16,777,216 bytes
게임코드: BDKJ
```

패치 적용 전에는 가능하면 원본 ROM의 SHA-256을 확인해 주세요. 다른 덤프, 헤더가 추가된 ROM, 이미 수정된 ROM에 적용하면 화면 깨짐이나 실행 오류가 발생할 수 있으며 결과를 보장하지 않습니다.

Windows PowerShell에서는 예를 들어 다음처럼 SHA-256을 확인할 수 있습니다.

```powershell
Get-FileHash "DigiCommunication Nyo - Datou! Black Gemagema Dan (Japan).gba" -Algorithm SHA256
```

### 패치 후 문제가 생긴다면

먼저 다음을 확인해 주세요.

- 원본 ROM SHA-256이 위 값과 정확히 일치하는지
- 이미 다른 패치가 적용된 ROM을 사용하지 않았는지
- IPS 패치를 두 번 적용하지 않았는지
- 오래된 세이브스테이트를 새 ROM에 강제로 불러오지 않았는지

mGBA 세이브스테이트는 VRAM 등 런타임 상태를 같이 저장할 수 있으므로, 그래픽이나 문구 확인 시에는 가능하면 **새 패치 ROM을 처음부터 실행하거나 일반 세이브를 사용**하는 것을 권장합니다.

문제가 계속되면 GitHub Issues에 사용한 원본 ROM의 SHA-256, 에뮬레이터 이름/버전, 발생 화면을 함께 남겨 주세요.

저장소 본문에는 ROM이나 IPS 바이너리를 커밋하지 않으며, 소스 코드와 번역/분석용 텍스트 자료만 보존합니다.

## 3. 패치 내용

현재 작업 기준 주요 항목:

- 재삽입 대상 메시지 **4,669 / 4,669 번역**
- 일반 추출에서 빠졌던 recovered 메시지 **142개** 반영
- 고정폭/raw UI 문자열 **311개** 반영
- 12x12 / 10x10 한글용 완성형 음절 **2,350자**
- 이름 입력 한글/받침 처리 및 8x8 폰트 확장
- 미니게임 숫자 단위, 날짜, 상태 라벨, 캐릭터명 등 한글화
- 카드/메뉴/자막/일반 이미지 등 그래픽 한글화 작업

그래픽 자산은 저작권 및 저장소 공개 범위 때문에 Git에는 포함하지 않습니다. 패치 릴리스에는 게임 원본 데이터가 아니라 **원본에 적용하는 차분 패치만** 배포하는 방식을 사용합니다.

자세한 구현 및 과거 수정 내역은 `STATUS.md`를 참고하세요.

## 4. 번역 품질에 대한 안내

이 프로젝트의 번역은 **AI 기반 초벌 번역 + 수동 수정/검증** 방식으로 진행되었습니다.

따라서 다음과 같은 문제가 남아 있을 수 있습니다.

- 원문만으로 화자를 특정하기 어려워 존댓말/반말 또는 캐릭터 말투가 흔들리는 경우
- 같은 용어가 장면에 따라 다르게 번역된 경우
- 일본어 말장난, 고유명사, 캐릭터 어미의 뉘앙스가 충분히 살아나지 않은 경우
- 고정 슬롯의 바이트 제한 때문에 의미를 유지하며 짧게 축약한 문장
- 화면에서 발견하지 못한 미번역 문자열이나 그래픽 문구

플레이 중 이상한 문장을 발견하면 **현재 한국어 문장만 보고 수정하지 말고 일본어 원문과 앞뒤 장면을 확인**해 주세요.

번역 수정/검수를 하려는 경우에는 먼저 [`TRANSLATION_GUIDE.md`](TRANSLATION_GUIDE.md)를 읽어 주세요. `assets/translation/messages.json`에는 일본어 `text`와 한국어 `translation`이 함께 있으므로 원문 대조가 가능합니다.

## 5. 저장소에 포함된 자료

이 저장소는 배포 페이지 역할과 함께, 패치가 어떻게 만들어졌는지 확인하고 번역을 수정할 수 있도록 소스 자료를 공개합니다.

### 번역/추출 텍스트

`assets/translation/`

- `messages.json` — 메인 메시지. 일본어 `text`와 한국어 `translation`, 위치 정보 포함
- `recovered_messages_ko.json` — 별도 복구 메시지
- `ui_strings.json` — 고정폭/raw UI 원문과 위치 정보
- `ui_strings_ko.json` — 고정폭/raw UI 번역
- `GLOSSARY.md`, `glossary.tsv` — 고유명사/말투/용어 기준
- `hangul_map.json` — 한글 코드 매핑

### 구조/메타데이터

- `assets/build_invariants.json`
- `assets/captions_index.json`
- `assets/images_index.json`
- 이미지/OBJ 관련 JSON·TSV manifest 및 spec

이미지 파일 자체가 아니라 **오프셋, 크기, 파일명, 구조 등 개발용 메타데이터**만 공개합니다.

### 도구

`tools/`에는 프로젝트 전용 패처와 분석/검증 도구, 그리고 작업 당시 사용한 공용 GBA 도구의 핵심 스냅샷이 있습니다.

개발/직접 수정에 관한 자세한 설명은 [`DEVELOPMENT.md`](DEVELOPMENT.md)를 참고하세요.

## 6. 번역을 수정하려는 경우

반드시 다음 순서를 권장합니다.

1. [`TRANSLATION_GUIDE.md`](TRANSLATION_GUIDE.md)를 먼저 읽습니다.
2. `assets/translation/GLOSSARY.md` / `glossary.tsv`에서 기존 표기를 확인합니다.
3. `messages.json`의 **일본어 `text`와 한국어 `translation`을 함께 비교**합니다.
4. 가능하면 실제 게임 장면에서 화자와 앞뒤 문맥을 확인합니다.
5. `$0`, `$1`, `%d`, 줄바꿈 등 제어 토큰을 보존합니다.
6. 고정 슬롯 문장은 실제 인코딩 바이트 길이 제한을 확인합니다.

AI를 이용해 재번역할 경우에도 **AI에게 한국어 기존 번역만 주지 말고 일본어 원문, 화자/장면 정보, 용어집을 같이 제공**해 주세요. 자동 번역 결과를 무검수로 일괄 덮어쓰는 방식은 권장하지 않습니다.

## 7. 공개 저장소에 포함하지 않는 것

`.gitignore`에서 다음 게임/바이너리 자산을 제외합니다.

- `.gba`, `.rom`, `.bin`, BIOS
- `.sav`, `.ss1` 등 세이브/세이브스테이트
- 원본 또는 번역 PNG/JPG/PSD/XCF/SVG
- TTF/OTF 등 폰트 바이너리
- IPS/BPS/xdelta 및 로컬 빌드 결과물
- ROM에서 잘라낸 실제 게임 바이너리/그래픽/음원

반면 `messages.json`처럼 **텍스트/JSON/TSV 형태로 추출한 원문과 구조 메타데이터는 후속 검수와 개발을 위해 저장소에 포함**합니다.
